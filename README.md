# Mother Tongue Instruction, Learning and Employment: Evidence from Ethiopia

Repository: [lemitaye/mti_learning_yl](https://github.com/lemitaye/mti_learning_yl).
Local project: `My Drive/Research/mti_learning_yl`.

Replication code and manuscript for the paper by **Teferi Mergo** (University of
Waterloo) and **Lemi Daba** (University of Maryland). The study estimates the causal effect
of mother-tongue instruction (MTI) on cognitive test scores and employment using
the **Young Lives** longitudinal survey of Ethiopia (rounds 1–5, 2002–2016) plus
the 2012–13 School Survey, via an **IV / 2SLS** design.

## Reproducing the results

**Requirements:** R (≥ 4.x) and a LaTeX distribution. `code/_master.R` checks
the required packages and installs missing ones automatically (internet access
and a writable R library are needed). It obtains `starpolishr` from GitHub,
installing `remotes` if needed, and does not deliberately upgrade existing
packages. For manual setup, the R packages are:
`tidyverse`, `haven`, `scales`, `stargazer`, `AER`, `lfe`, `fastDummies`,
`xtable`, `clubSandwich`, and `starpolishr` (GitHub only):

```r
install.packages(c("tidyverse","haven","scales","stargazer","AER","lfe","fastDummies","xtable","clubSandwich"))
remotes::install_github("ChandlerLutz/starpolishr")
```

**Run the whole pipeline** from the project root:

```r
source("code/_master.R")     # or:  Rscript code/_master.R
```

Generated tables and figures are saved in `output/` and mirrored to the revision
Dropbox/Overleaf project (see Dual output export below). Set
`MTI_OVERLEAF_DIR=''` when validating locally. Review the generated results before
using them in the manuscript; the historical table differences below still apply.

### Table 2 diagnostics and reproduction caveat (Tables 4, 5)

Table 2 is now reproducible with `Rscript code/07_table_main.R`. It stages
`output/tables/tableII_mod.tex` and `tableII_mod_diagnostics.csv`, retaining the
original four employment-model coefficients, SEs, stars, and sample sizes. The
generator uses the actual full controls in `05_estimation.R`; the former manuscript
note was incomplete. It adds sample-specific excluded-instrument F statistics,
partial R-squared, HC1 first-stage F statistics, and conventional/HC1 Anderson–Rubin
tests of a zero MTI effect. These calculations do not resolve few-region-cluster
inference. Original estimates were cross-checked against `AER::ivreg`; F tests
against nested-model ANOVA; and HC1 calculations against `sandwich::vcovHC`.

The manuscript's Table 4 (`tableIII`) and Table 5 (`tableV`) still have a
December-2023/November-2022 generator mismatch. Recover or reconstruct their
generators before replacing them with staged output. Reproducing Table 2's
employment columns does not establish reproduction of these other tables.

## Regional clustering for Table 2

`07_table_main.R` now calls `code/helpers/cluster_inference.R`. It retains original
conventional inference for comparison and adds CR2/Satterthwaite regional
inference, clustered AR tests and an enumerated within-region-orthogonalized AR
sign-flip sensitivity check. `clubSandwich` is now a required package and is
installed automatically by the master script. Standalone runs need it installed.

Salary CR2 p-values are 0.172 and 0.194; no Table 2 coefficient rejects at 5%.
Only four regions (three excluding Amhara) are available. In the sign-flip check,
Tigray has no residual instrument variation, leaving three/two informative
regions and extremely coarse p-values. This is a sensitivity analysis, not an
exact randomization test or a cure for arbitrary regional shocks.

The diagnostics CSV includes CR2 confidence intervals, effective d.f., first-stage
and AR checks. `tableII_mod_cluster_audit.csv` records regional sample sizes,
residual instrument variation and scores. Run
`Rscript temp/tests/check_table2_clustering.R` to verify estimates, samples,
Satterthwaite calculations, row/cluster-label invariance and sign enumeration.
The local viewer includes a detailed clustering note; its build still does not
rerun regressions. Original Table 2 significance is not robust to clustering.
